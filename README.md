# Agri-Energy Connect 

Agri-Energy Connect is an ASP.NET Core MVC web application designed to bridge the gap between agriculture and green energy. The platform enables farmers and employees to interact with agricultural product data and renewable energy information through a secure, role-based system, supporting sustainable farming practices and informed decision-making.

---

## Project Overview

The goal of Agri-Energy Connect is to demonstrate how modern web technologies can be used to integrate agricultural management with clean energy concepts. The application implements role-based authentication, allowing different user types to access features relevant to their roles.

This project was developed as part of an academic portfolio to showcase practical skills in C#, ASP.NET Core MVC, and software design principles.

---

## User Roles & Features

### Farmer
- Register and log in securely
- Add and manage agricultural products
- View product information linked to green energy concepts

### Employee
- Log in using role-based authentication
- View and analyse agricultural and green energy data
- Access system information relevant to sustainability initiatives
